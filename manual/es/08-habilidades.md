# Habilidades (skills)

Las habilidades son capacidades extra que añades tú. Usan el formato SKILL.md de Claude, OpenClaw y Hermes: una carpeta con un archivo SKILL.md (nombre, descripción e instrucciones) y, si hace falta, sus programas. Así puedes usar las que comparte la gente.

## Añadir una (Ajustes → Habilidades)

- **Añadir habilidad (carpeta)**: eliges la carpeta que tiene el SKILL.md.
- **Añadir habilidad (ZIP)**: eliges el .zip descargado.
- Se copian a los datos de la aplicación (carpeta skills). **Abrir la carpeta de las tuyas** la enseña. **Quitar** borra una tuya.
- Cada una dice si es «de serie» o «tuya», si «funciona sola en cada latido», si «pide permiso» y si es «con programa» o solo «instrucciones».

## Dársela a un agente

En su ficha → Capacidades → marca «Habilidades extra» y elige cuáles. También puedes poner una en «En cada latido, sin cerebro (no gasta)» para que se ejecute sola cada vez que despierta.

## Cómo las usa

- Una habilidad de **solo instrucciones** (como las de Claude): el agente recibe sus instrucciones para seguirlas en esa tarea, y la dirección de su carpeta. Si tiene programas y el agente tiene «Tu ordenador como tú», puede ejecutarlos.
- Una habilidad **con programa** se ejecuta en tu ordenador. Lo que trae de fuera llega como datos, no como órdenes.

## Cuidado

Una habilidad con programa se ejecuta en tu ordenador con tus permisos: añade solo las que vengan de alguien de confianza.

## Las de serie

El Vigía de X (busca tuits sobre IA cada vez que despierta) y leer el correo. Leer webs, archivos y correo ya no son habilidades: son capacidades de cada agente.
