# Fer Casa (Fer Home)

Es el mismo programa que la aplicación, pero se lanza desde el Terminal y no tiene ventana: sirve para un ordenador siempre encendido, un móvil Android viejo o un servidor.

- Lanzarlo: node fer-home.mjs (necesita Node 18 o más moderno).
- Claves: node fer-home.mjs keys. Correo: node fer-home.mjs correo. Telegram del edificio: node fer-home.mjs telegram.
- Desde otro aparato de tu casa: abre la dirección que te dice al arrancar y pon el PIN. El PIN impide que otro de tu red use tu saldo.
- Las claves se guardan en data/config.json, en ese ordenador.

Si solo usas tu Mac o tu PC, no necesitas Fer Casa: la aplicación ya lo lleva dentro.
