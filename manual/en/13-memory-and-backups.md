# Memory and backups

## Short memory

Each agent remembers the latest things it has done and talked about (its short memory). «Start from scratch» clears it.

## Long-term memory (Memory)

When a chat has been quiet for 10 minutes, Memory keeps what matters in the long-term memory, each fact under its topic (one per person or company and one per project) and with its origin. First, JEV decides whether it's worth it: a chat with nothing useful isn't filed. Agents search it by words.

## The building's brain in a folder (Settings → Brain)

«Change the folder»: if you choose a folder inside Google Drive for desktop, the memory is also in Drive and you can open it in Obsidian. Inside: «Library» (your notes), «Long-term memory» (written by Memory, one note per topic) and a copy of the building. What you correct by hand is respected.

## Save a backup

The save button at the top: in red if there's no backup or it's more than 7 days old.

## The automatic mode in only one place

Leave the automatic mode (no pause) in only one place: if the app and Fer Home, or two computers, run the same building at the same time, it spends twice.
