# Meetings and loops

«Meetings» button. Up to 10 agents at the table, counting the Boss. You call them or the Boss proposes them.

## Kinds

- **Debate**: each one gives their view, round after round; the Boss chairs and writes the minutes.
- **Loop: improve**: each one takes the whole version from the previous one and improves it, round after round, in order. All versions are kept.
- **Loop: continue**: each one carries on the text where the previous one left it.

The agenda takes up to 60,000 characters. The minutes carry the result as it is and a summary by the Boss.

## If something fails

If an agent fails in a meeting, it's tried once more; if it fails again, its turn is skipped and the meeting goes on. It only stops if they all fail in a row. An interrupted meeting has the «Resume» button.

## Tip

Several cheap brains reviewing each other can improve an answer a lot. Try an «improve» loop with 3 or 4 cheap agents.
