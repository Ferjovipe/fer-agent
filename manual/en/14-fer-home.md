# Fer Home

It's the same program as the app, but started from the Terminal and without a window: for an always-on computer, an old Android phone or a server.

- Start it: node fer-home.mjs (needs Node 18 or newer).
- Keys: node fer-home.mjs keys. Email: node fer-home.mjs email. The building's Telegram: in Settings → Telegram (or node fer-home.mjs telegram).
- From another device at home: open the address it shows when it starts and enter the PIN. The PIN stops anyone else on your network using your balance.
- The keys are kept in data/config.json, on that computer.

If you only use your Mac or PC, you don't need Fer Home: the app already has it inside.
